# Capstone 1 Project - Pinnacle Shield Insurance:
The purpose of this repo is to showcase my skills in HTML5, CSS3, Flexbox, Bootstrap, Responsive Design, JavaScript, Git/GitHub and GitHub Actions. I will do this by creating a responsive website with HTML and CSS and add functionality to it by using Javascript. I will also use components from the Bootstrap framework to speed up development and improve functionality. Finally I will use GitHub actions to validate/test my code and then update my site to GitHub Pages.

## Features That Were Implemented:
**Responive Design:** My site has responsive design and will adapt and move components around as need be to fit into the different screen sizes of different devices users might view the site on. It does this through the use of 
media queries, Bootstrap and Flexbox.
<br>
<br>

**Bootstrap Components:** My site makes use of different components from the Bootstrap framework. Such as their Nav Bar for my site global Nav Bar and their Accordian component for the FAQ page.
<br>
<br>

**Insurance Quote Page:** My site has a responive quote system where a user can select what type of innsurance they want (auto, home, or life), put in their information and be given a monthly/annual premium quote along with a table breaking down 
the factors that went into deciding their quote amount.
<br>
<br>

**FAQ Page:** My site has an FAQ page that makes use of the Bootstrap Accordian component. The user can browse through the different question sections and can use the search feature at the top to search for a specific 
question or answer based off of what they input.
